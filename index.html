Chapter 2 – Probability

What is Probability?

Probability measures uncertainty and always lies between 0 and 1.

  • 0 → Impossible event
  • 1 → Certain event
Formula
P(E) = Favourable outcomes / Total outcomes

Sample Space and Event

The sample space (S) is the set of all possible outcomes.

Example

Tossing a coin: S = {H, T}

Equally Likely Events

All outcomes have equal chance of occurring.

Example

Fair letter die → Probability of each letter = 1/6

Complementary Events

Formula
P(A′) = 1 − P(A)

Mutually Exclusive Events

Formula
P(A ∪ B) = P(A) + P(B)

Independent Events

Formula
P(A ∩ B) = P(A) × P(B)

Dependent Events

Formula
P(A ∩ B) = P(A) × P(B|A)

Conditional Probability

Formula
P(A|B) = P(A ∩ B) / P(B)

Bayes’ Theorem

Formula
P(A|B) = [P(B|A) × P(A)] / P(B)

Applications

  • Weather forecasting
  • Medical diagnosis
  • Machine learning
  • Finance
